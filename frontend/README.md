# 🎙️ Nuzio AI — Frontend Application

Modern, audio-first live news feed application built with **React 19**, **Vite**, **Tailwind CSS**, and **Web Speech API**.

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build
```

## 📱 Features

- **Live News Stream (NewsData.io)**: Real-time breaking headlines with instant one-tap refresh, live search modal, and live badge indicator.
- **Pure Audio Narration**: Crystal-clear bilingual AI narrator voices (English & Hindi) with speed cycling (`1x`, `1.25x`, `1.5x`, `2x`), scrubber seeking, and audio visualizer.
- **Step-by-Step Onboarding**: Language Selection &rarr; Login / Sign Up &rarr; Niches Selection &rarr; Personalized Live Discover Stream.
- **Dynamic iOS Status Bar**: Real-time battery indicator, dynamic Wi-Fi/Cellular network detector, and live clock.
- **12 Interactive Niches**: Comprehensive category coverage with MongoDB user preference persistence.
